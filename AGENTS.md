# Project Guidelines & Agent Instructions

## UI & Design Guidelines
Before any UI work, reference the `ui-craft` skill (`.agents/skills/ui-craft/SKILL.md`) and follow `DESIGN.md` (when present).
Always adhere to:
- Explicit design tokens for type, colors, spacing, borders, and motion (no raw hex or ad-hoc spacing).
- Complete state handling (loading skeletons, empty states, error states, and success confirmations).
- Intentional hierarchy and high-quality feedback/affordances.
